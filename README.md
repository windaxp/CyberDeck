# 🚀 CyberDeck v9.3

**CyberDeck** — это мощный модульный мультитул для управления Android-устройствами через ADB прямо из Termux. Твой личный цифровой швейцарский нож, объединяющий полезные утилиты, системную диагностику и безбашенные пранки.

## ⚡ Возможности

### 🖥️ Информация и Диагностика
*   **Neofetch**: Кастомный вывод системной информации (CPU, RAM, Android, Kernel) с фирменным логотипом CyberDeck.
*   **Мониторинг батареи**: Узнай заряд, температуру и статус аккумулятора.

### 🕵️ Шпионские штучки
*   **Сбор логов**: Вытаскивает системные логи Android прямо в папку `logs`.
*   **Скриншоты**: Делает снимок экрана и сохраняет его.
*   **Активное окно**: Показывает, какое приложение сейчас открыто на телефоне.

### 🧹 Чистка и Оптимизация
*   **Деблоат**: Удаление системной рекламы и аналитики (адаптировано под Xiaomi, Samsung, Tecno и др.).
*   **Очистка (Cleaner)**: Удаляет весь мусор (логи, скрины) и чистит кэш Android одной кнопкой.

### 😈 Пранки и Развлечения (ALL-IN-ONE)
*   **Аудио-скример**: Берет случайный `.mp3` из папки и врубает его на полную громкость.
*   **Полтергейст**: Телефон начинает сам хаотично тыкать в экран.
*   **Тикток-Зомби**: Бесконечный скролл ленты.
*   **Автокликер**: Автоматические нажатия по заданным координатам.
*   **Смена DPI**: Режимы «Бабушкин телефон» и «Муравей».
*   **Голос из телефона (TTS)**: Телефон озвучивает любой введенный тобой текст.
*   **Отключение сети**: Блокирует Wi-Fi и мобильный интернет.

### ⚙️ Утилиты
*   **Встроенный проводник**: Файловый менеджер прямо в терминале (навигация, удаление файлов, переход по системным путям).
*   **Менеджер приложений**: Показывает список установленных программ и позволяет удалить любую по номеру.
*   **Бэкапы**: Сохранение текущей версии скрипта в папку `backup`.
