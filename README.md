# 🚀 CyberDeck v11

**CyberDeck** — это мощный модульный мультитул для управления Android-устройствами через ADB прямо из Termux. Твой личный цифровой швейцарский нож, объединяющий полезные утилиты, системную диагностику и безбашенные пранки.

## ⚡ Возможности

### 🖥️ Информация и Диагностика
*   **Neofetch**: Кастомный вывод системной информации (CPU, RAM, Android, Kernel, Uptime, Screen, Battery, Temp) с фирменным логотипом CyberDeck.
*   **Мониторинг батареи**: Узнай заряд, температуру и статус аккумулятора.
*   **Температура батареи**: Отдельный пункт меню — три источника данных (dumpsys, power_supply, thermal_zone), цветовая индикация от ❄️ до 💀.

### 🕵️ Шпионские штучки
*   **Сбор логов**: Вытаскивает системные логи Android прямо в папку `logs`.
*   **Скриншоты**: Делает снимок экрана и сохраняет его.
*   **Активное окно**: Показывает, какое приложение сейчас открыто на телефоне.
*   **Скрытый снимок**: Фото через камеру или скриншот — сохраняется в `screenshots/`.

### 🧹 Чистка и Оптимизация
*   **Деблоат**: Удаление системной рекламы и аналитики (адаптировано под Xiaomi, Samsung, Tecno, Infinix и др., автоопределение бренда).
*   **Очистка (Cleaner)**: Удаляет весь мусор (логи, скрины) и чистит кэш Android одной кнопкой.

### 😈 Пранки и Развлечения (ALL-IN-ONE)
*   **Аудио-скример**: Берет случайный `.mp3` из папки и врубает его на полную громкость.
*   **Полтергейст**: Телефон начинает сам хаотично тыкать в экран.
*   **Тикток-Зомби**: Бесконечный скролл ленты.
*   **Бешеное вращение экрана**: Экран крутится туда-сюда.
*   **Автокликер**: Автоматические нажатия по заданным координатам.
*   **Смена DPI**: Режимы «Бабушкин телефон» и «Муравей».
*   **Рикролл**: Открывает классику на телефоне.
*   **Спам уведомлениями**: Фейковое «ОБНАРУЖЕН ВИРУС! 😈».
*   **Отключение сети**: Блокирует Wi-Fi и мобильный интернет.
*   **Фейк батареи**: Показывает любой процент заряда (и сброс обратно).
*   **Hacker UI**: Включает отображение касаний и координат указателя.

### ⚙️ Утилиты
*   **Встроенный проводник**: Файловый менеджер прямо в терминале (навигация, удаление файлов, переход по системным путям).
*   **Менеджер приложений**: Показывает список установленных программ и позволяет удалить любую по номеру.
*   **Бэкапы**: Сохранение текущей версии скрипта в папку `backup`.

### ☠️ Опасная зона
*   **Смена PIN-кода**: Установка нового PIN экрана блокировки.
*   **Kernel Panic**: Мгновенное выключение устройства (требует ввода `PANIC`).

## 📁 Структура проекта

Все папки создаются автоматически при первом запуске **прямо в корне со скриптом**:

```
cyberdeck/
├── cyberdeck.py        # Главное меню
├── all_in_one.py       # Пранки и шпионаж
├── app_manager.py      # Менеджер приложений
├── neofetch.py         # Системная информация
├── scripts/            # Скрипты для запуска из меню
├── screams/            # MP3 для скримера
├── screenshots/        # Скриншоты
├── logs/               # Логи Android
└── backup/             # Бэкапы скриптов
```

## 🛠 Установка и запуск

### 1. Подготовка
Установи [Termux](https://f-droid.org/packages/com.termux/) (рекомендуется версия с F-Droid) и выполни:
```bash
pkg update -y
pkg install python android-tools git -y
```

### 2. Подключение телефона
Включи «Отладку по USB» и подключи телефон:
```bash
adb devices
adb connect 127.0.0.1:5555   # для беспроводного подключения
```

### 3. Запуск
```bash
python cyberdeck.py
```

> 💡 **Совет**: Для скримера закинь пару `.mp3` в папку `screams/` — иначе пранк не сработает.
